## Opening URLs

To open a URL in the user's browser (Chromebook), SSH to the `zhromebook` host and use the garcon URL handler:

```bash
ssh zhromebook 'garcon-url-handler "<url>"'
```

`zhromebook` is configured in `~/.ssh/config` (HostName 100.86.36.96, User zonca).
